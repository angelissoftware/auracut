Editor de vídeo com IA

O AuraCut é um editor de vídeo pessoal que roda no computador do próprio usuário. Ele recorta as melhores jogadas de gravações de jogos, monta vídeos curtos (Shorts) com efeitos, legendas e narração, e publica esses vídeos nos canais do YouTube do próprio usuário, nos horários que ele escolher.

Como o AuraCut usa o YouTube

  • O usuário conecta os seus próprios canais com o login do Google.
  • O AuraCut usa a API de Dados do YouTube só para enviar e agendar os vídeos que o próprio usuário criou e para mostrar o nome e a foto do canal conectado.
  • Os dados de acesso ficam guardados apenas no computador do usuário. Nada é vendido nem compartilhado.

O AuraCut usa os Serviços de API do YouTube. Ao usar o AuraCut, você concorda com os Termos de Serviço do YouTube.

English

AuraCut is a personal video editor that runs on the user's own computer. It cuts highlights from gameplay recordings, builds short videos (Shorts) with effects, captions and narration, and publishes them to the user's own YouTube channels at the times the user chooses. AuraCut uses the YouTube Data API only to upload and schedule videos created by the user and to display the connected channel's name and picture. Access tokens are stored only on the user's computer and are never sold or shared. AuraCut uses YouTube API Services; by using AuraCut you agree to the YouTube Terms of Service.
