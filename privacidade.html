Política de Privacidade

Última atualização: 9 de outubro de 2026

Esta política explica quais dados o AuraCut ("o aplicativo") acessa, como usa, onde guarda e como você pode apagar esses dados. O AuraCut é um editor de vídeo pessoal que roda no computador do próprio usuário.

1. Dados que acessamos

Quando você conecta um canal do YouTube com o login do Google, o AuraCut pede permissão para:

  • Enviar vídeos para o seu canal (escopos youtube.upload e youtube);
  • Ler informações básicas do canal: nome, ID e foto (escopo youtube.readonly), só para mostrar qual canal está conectado.

O AuraCut também trabalha com os vídeos e áudios que você mesmo envia para ele (gravações de jogos, músicas e narrações).

2. Como usamos os dados

  • Para enviar e agendar no YouTube os vídeos que você criou no AuraCut, com o título, a descrição e as tags que você definiu;
  • Para mostrar na tela qual canal está conectado.

Não usamos os dados para publicidade, não criamos perfis e não lemos, alteramos nem apagamos outros vídeos, comentários ou dados da sua conta.

3. Onde os dados ficam guardados

Os tokens de acesso do Google e os seus vídeos ficam guardados somente no computador onde o AuraCut está instalado. Não existe servidor do AuraCut na nuvem que receba esses dados. Os vídeos só saem do computador quando são enviados diretamente para o YouTube, a seu pedido.

4. Compartilhamento

Não vendemos, alugamos nem compartilhamos os seus dados com ninguém. Os únicos dados enviados para fora do computador vão para o próprio Google/YouTube (para publicar os vídeos) e, quando a narração por IA é usada, o texto da fala é enviado ao serviço de voz da Microsoft (Edge TTS) para gerar o áudio.

5. Serviços de API do YouTube e Google

O AuraCut usa os Serviços de API do YouTube. Ao usar o AuraCut, você também está sujeito aos Termos de Serviço do YouTube e à Política de Privacidade do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

6. Como remover o acesso e apagar os dados

  • No AuraCut, use “desconectar” no canal: o token daquele canal é apagado do computador.
  • A qualquer momento você pode remover o acesso do AuraCut à sua conta em myaccount.google.com/permissions (Configurações de segurança do Google).
  • Apagar a pasta do AuraCut do computador apaga todos os dados guardados por ele.

7. Crianças

O AuraCut não é direcionado a menores de 13 anos e não coleta dados de crianças de propósito.

8. Mudanças nesta política

Se esta política mudar, a nova versão será publicada nesta página com a data de atualização.

Privacy Policy (English)

Last updated: October 9, 2026

Data accessed. When you connect a YouTube channel with Google Sign-In, AuraCut requests permission to upload videos to your channel (youtube.upload, youtube) and to read basic channel information — name, ID and picture (youtube.readonly) — only to show which channel is connected. AuraCut also processes the videos and audio files you provide.

Use. Data is used only to upload and schedule on YouTube the videos you created in AuraCut, with the title, description and tags you set, and to display the connected channel. We do not use data for advertising, build profiles, or read, modify or delete any other content in your account.

Storage. Google access tokens and your videos are stored only on the computer where AuraCut is installed. There is no AuraCut cloud server receiving this data.

Sharing. We do not sell, rent or share your data. Data leaves your computer only to Google/YouTube (to publish your videos) and, when AI narration is used, the narration text is sent to Microsoft's text-to-speech service to generate audio.

YouTube API Services. AuraCut uses YouTube API Services. By using AuraCut you agree to the YouTube Terms of Service and the Google Privacy Policy. AuraCut's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data. Use “disconnect” on a channel in AuraCut to delete its token from the computer, or revoke AuraCut's access at any time at myaccount.google.com/permissions. Deleting the AuraCut folder deletes all data it stored.

Children. AuraCut is not directed to children under 13.
